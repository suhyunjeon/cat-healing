# 애봉이의 식탁

고양이에게 밥을 주고 쓰다듬으며 쉬어가는 웹 힐링 게임입니다.

## 기능

- 햇살 가득한 방 배경, 상단 상태 표시, 화면 하단 돌봄 메뉴
- 밥과 간식 주기, 쓰다듬기, 눈을 감고 낮잠 자기
- 물 주기·수분 저장, 브러싱, 창가 구경
- 설정·일지·꾸미기·놀이를 별도 창에서 열기
- 건강하게 키우기: 유산균(30), 오메가3(50), 줄기세포(1,000), 엑소좀(500하트)의 가상 돌봄, 아이템별 하루 1회 행복 +5 및 기록 저장
- 배부름 100%가 되면 자동으로 화장실에 다녀오기 (이후 배부름 55%)
- 물을 마셔 수분 100%가 되면 자동으로 소변 보기 (이후 수분 55%)
- 화장실에서 맛동산과 소변 모래를 구분해 확인·청소하기, 브라우저에 각각 개수 저장
- 배부름·행복 상태와 하트 모으기
- 고양이 이름 입력 및 브라우저 저장
- 치즈냥·턱시도·샴·회색냥·삼색이·카오스·먼치킨·검정냥이·폴드·흰고양이·아비시니안·고등어 코숏·아메숏·러시안블루·랙돌·벵갈·브리티시 숏헤어·페르시안 캐릭터 선택 및 브라우저 저장
- 시간 제한 없는 낚싯대 미니게임과 하트 보상
- 매일 초기화되는 미션과 친밀도 성장
- 하트로 구입하고 배치하는 방 소품
- 고급 사랑빗(120), 체크 담요(160), 라운지 스크래쳐(220), 프리미엄 이동장(300하트) 장식
- 프리미엄 정수기(180), 자동급식기(350), 라탄 침대(450), 원목 캣타워(650), 캣휠(900), 자동화장실(1,200), 순금 캣타워(5,000하트) 장식
- 모바일 화면 지원과 선택 가능한 효과음

## 추억과 모험

- 돌봄 5번마다 보은 선물, 8종 수집 도감, 5번째 선물마다 희귀 아이템
- 하루 한 번 택배 상자 탐험: 아이템과 하트 보상
- 고양이 종류별 성격과 간식·장난감·잠자리 취향 발견
- 레이저·생선 잡기·상자 숨바꼭질: 시간 제한 없이 보상과 일일 놀이 미션 연동
- 이름·고양이 모습·날짜가 남는 13종 추억 카드
- 게임 속 일일 날씨와 실제 시간대에 따른 햇살·빗소리·밤 우다다
- 친밀도 40/100/180에 꾹꾹이·배 보여주기·무릎 잠자기 해금
- 배치한 순금 캣타워 등반과 기념 카드
- `cozy-cat-adventures-v1`에 저장하며 미접속 벌점은 없습니다.

## 실행

별도의 패키지 설치나 빌드가 필요하지 않습니다.

```sh
python3 -m http.server 5188 --directory dist
```

브라우저에서 <http://localhost:5188>을 여세요.

## Render 배포

Render에서 **New → Static Site**를 선택하고 이 GitHub 저장소를 연결하세요.

| 설정 | 값 |
| --- | --- |
| Branch | `main` |
| Build Command | `echo 'Static files are ready'` |
| Publish Directory | `dist` |

Root Directory는 비워 둡니다. Start Command와 환경 변수는 필요하지 않습니다.
배포가 완료되면 Render가 발급한 `https://…onrender.com` 주소로 접속하세요.

또는 **New → Blueprint**에서 저장소를 연결하면 루트의 `render.yaml` 설정을 사용할 수 있습니다.
기존 사이트와 Render 사이트는 주소가 다르므로 저장한 이름과 캐릭터는 서로 공유되지 않습니다.

## 파일

- `dist/index.html`: 게임 화면과 SVG 캐릭터
- `dist/style.css`: 화면 스타일과 애니메이션
- `dist/game.js`: 게임 동작 및 설정 저장
- `dist/room.js`: 방 메뉴, 물 주기와 브러싱
- `dist/assets/cozy-room.png`: 생성한 방 배경 일러스트
- `ASSET-NOTES.md`: 배경 생성 방식과 프롬프트
- `.openai/hosting.json`: 기존 Sites 배포 연결 설정

이름과 캐릭터 선택은 해당 브라우저에 저장됩니다. 배부름·행복·하트·친밀도·미션·구입한 소품도 해당 브라우저에 저장됩니다.
